# 🎓 Projeto Universidade - Spring Boot & JPA

Este projeto é uma aplicação desenvolvida em **Java** utilizando **Spring Boot** e **Spring Data JPA (Hibernate)**, integrada com uma base de dados **PostgreSQL**, estruturada seguindo os padrões do **Maven**.

## 🚀 Tecnologias Utilizadas

* **Java** (Versão 17+)
* **Spring Boot** (3.3.0)
* **Spring Data JPA / Hibernate**
* **PostgreSQL**
* **Maven**

---
